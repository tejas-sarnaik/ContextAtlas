# Research roadmap

- **R1:** Model-specific exact tokenizers, document-aware chunking, source-length overhead accounting.
- **R2:** Query-aspect coverage, submodular objectives and constrained Pareto-front search.
- **R3:** Reranker/embedding backends, multilingual evaluation and gold-support annotations.
- **R4:** Answer-grounding and calibrated abstention tests using controlled LLM evaluation.
- **R5:** Benchmark against top-k, MMR, exact knapsack and learning-based context compression on public corpora. Report uncertainty across seeds.

The initial selector is a deterministic heuristic; the repository makes no claims of state-of-the-art performance or novel theoretical guarantees.
