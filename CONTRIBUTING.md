# Contributing to ContextAtlas

Thanks for contributing. Open an issue before major changes; keep PRs focused and add tests for new behavior.

```bash
python -m unittest discover -s tests -v
python -m contextatlas analyze datasets/demo.json
```

Contributions of alternate tokenizers, benchmark adapters, evaluation metrics, and UI accessibility improvements are welcome. Do not submit proprietary or private documents in examples/issues. By contributing you agree your changes are licensed under MIT.
